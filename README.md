# 🌌 EternalEcho（永恒回响）- 3D 电影级时空记忆画廊与浪漫相册

> 专为送给另一半打造的 **Awwwards 级高定数字浪漫体验**。
> 融合 **Three.js 3D 空间计算**、**四大 3D 聚合形态（3D立体爱心 / 斐波那契记忆星球 / 双螺旋阶梯 / 3D环形走马灯 / 双层爆炸魔方）**、**致两载春秋的深情长信**、**顺序歌曲与视频原声联动播放**。
> **100% 纯前端静态架构，零后端依赖**，完全自适应电脑 Chrome/Edge、iPad 触控与手机微信 H5。

---

## ✨ 核心亮点与 3D 交互特效

### 1. 💖 科技浪漫：Three.js 3D 五大空间聚合形态
- **♥ 3D 立体旋转大爱心（Heart）**：数百张甜蜜合照在 3D 空间中聚拢成一颗立体跃动的三维爱心，随音乐与节奏缓缓自转。
- **🌐 斐波那契记忆星球（Sphere）**：基于黄金分割斐波那契螺旋算法，将所有回忆紧密包裹成一颗璀璨星体。
- **🧬 命运双螺旋阶梯（Helix）**：象征如 DNA 般永恒交织的岁月阶梯，每一级阶梯皆为时光印记。
- **🎠 3D 环形走马灯画廊（Carousel）**：电影级旋转木马布局，带地面镜面水波倒影与柔和景深，支持鼠标或指尖自由拖拽无极滑行。
- **🎲 双层 3D 爆炸旋转魔方（Exploding Cube）**：内层小魔方缓缓自转，外层大魔方悬停时向四周炸开散发，配合飘樱爱心粒子，视效震撼！

### 2. 🪞 双面相框（Double-Sided Photo Plaque）
- 无论用户如何 360° 旋转、仰视或俯视，正反两面均为高精照片，彻底杜绝翻转后看到黑白背板的缺陷。
- 智能极角限制（Polar Angle Clamp），避免视角天地颠倒翻车，操控体验极为顺滑。

### 3. 📜 终章：时光长卷·致两载春秋的深情长信
- 顶部导航一键 0ms 即刻唤起烫金典雅长信手账，同时 3D 镜头平滑飞越至金色信封前。
- 细腻回顾从 2022 年初遇到 2024 年细水长流的七百余个日夜。

### 4. 🎵 智能多音轨顺序连播系统
- **第 1 首**：陈鸿宇《理想三旬》（官方浪漫主题曲）
- **第 2 首**：周杰伦《晴天》（经典心动恋曲）
- **第 3 首**：桌面专属视频原声 · 心动画卷（提取自珍贵录像视频）
- **第 4 首及后续**：平安夜录像原声独白、跨年夜钟声原声
- **无感顺滑衔接**：歌曲播完后自动无缝切入下一首；视频播放时歌曲自动静音让路，交互无冲突。
- **离线 Web Audio 容灾**：若遇到弱网或离线，自动启用内置 Web Audio 浪漫和弦合成器演奏。

### 5. 📱 手机端超清沉浸画报与多端适配
- 轻触任意照片立即唤出巨幕全屏，支持左右滑动换图、双击局部放大与下拉退出。
- 恋爱倒计时器毫秒级跳动，动态记录相遇至今的每一天、每一小时、每一秒。

## 🚀 本地运行

项目为纯静态网页，无需编译打包：

```bash
# 启动本地服务器
python -m http.server 8080

# 浏览器访问
http://localhost:8080
```

## 🌐 免费上线与部署

### 推荐一：GitHub Pages（一键免费上线）
1. 在 GitHub 仓库设置（Settings）-> **Pages**；
2. **Build and deployment** 选择 `Deploy from a branch`；
3. Branch 选择 `main` / `root`，点击 **Save**；
4. 稍等片刻即可获得专属 HTTPS 网址（如 `https://<用户名>.github.io/<仓库名>/`），在微信中直接分享！

### 推荐二：Vercel / Netlify / Cloudflare Pages
- 导入 GitHub 仓库后直接点击 Deploy 即可生成永久全球加速网址。
