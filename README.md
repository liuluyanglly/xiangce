## ✨ 核心亮点与 3D 交互特效

### 1. 💖 科技浪漫：Three.js 3D 五大空间聚合形态
- **♥ 3D 立体旋转大爱心（Heart）**：5 层三维立体建筑级架构（前置主面、立体外廓、后置心面、内层水晶晶格、环心倾斜星轨双环），545 张照片全部立体呈现且层次分明。
- **🌊 四轨时空光浪（Wave）**：近景大图细腻，中远景深邃延展，神经网络突触随浪流动。
- **🎠 五层罗马斗兽场时光回廊（Carousel）**：五层宏伟环形展厅，545 张照片分层环列，地面暗色玻璃倒影映射。
- **🌐 斐波那契记忆星球（Sphere）**：基于黄金分割斐波那契螺旋算法，球面 100% 垂直正立，零颠倒、零倒挂。
- **👣 时光足迹（Storyline）**：30 个月份时间轴全景长卷，大图自适应长宽比零裁剪预览。

### 2. 🪞 双面相框（Double-Sided Photo Plaque）
- 无论用户如何 360° 旋转、仰视或俯视，正反两面均为高精照片，彻底杜绝翻转后看到黑白背板的缺陷。
- 智能极角限制（Polar Angle Clamp），避免视角天地颠倒翻车，操控体验极为顺滑。

### 3. 📜 终章：时光长卷·致五载春秋的深情长信
- 顶部导航一键 0ms 即刻唤起典雅长信手账，同时 3D 镜头平滑飞越至金色信封前。
- 细腻回顾从 2021 年冬夜相识到 2026 年细水长流的 1780 多个日夜。

### 4. 🎵 智能多音轨顺序连播系统
- **第 1 首**：菲菲公主《第57次取消发送》（热门主打恋曲）
- **第 2 首**：陈鸿宇《理想三旬》（官方浪漫主题曲）
- **第 3 首**：周杰伦《晴天》（经典心动恋曲）
- **第 4 首及后续**：平安夜录像原声独白、跨年夜钟声原声
- **无感顺滑衔接**：歌曲播完后自动无缝切入下一首；视频播放时歌曲自动静音让路，交互无冲突。
